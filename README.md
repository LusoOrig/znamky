# Filatelistický katalog

Webová verze katalogu sbírky poštovních známek: **[otevřít katalog](https://lusoorig.github.io/znamky/)**.

- `03_APLIKACE/` – aplikace (HTML, CSS, JavaScript; data jsou vložena v `app.js`)
- obrázky (výřezy a náhledy) jsou v samostatném repozitáři [LusoOrig/znamky-obrazky](https://github.com/LusoOrig/znamky-obrazky), aby se aplikace nasazovala rychle

Originální fotografie (HEIC) ani pracovní databáze zde nejsou. Identifikace a ceny jsou orientační, určené z fotografií.
